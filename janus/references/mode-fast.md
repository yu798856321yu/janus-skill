# R0 快速档 (Mode Fast)

R0 处理风险不高于 `risk_r0_max`、目标明确、影响局部且不改变持久模型、公共契约、鉴权或外部信任边界的任务。它没有持久卷宗和 Gate。

## P1-P6

1. **锁定**：确认目标最终路径和既有修改；保存精确目标 preimage 与必要 VCS/模块元数据。回显 `mode: R0 | resume_supported: false | source_targets: [...] | change: ... | verify: ...` 后在既有授权内推进。
2. **实施前基准**：按 SKILL 共同入口取得适用失败断言、探针或保留行为基线；不为无影响说明强造失败测试。沿最近邻实现做最小改动，刻意捷径才记录 ponytail。
3. **写入记录**：在会话或独占 scratch 保存可信写前内容/逆补丁，写后立即记录 postimage。故障读取控制面 issue 规则；新风险按控制面升档协议暂停源码并保全现场。
4. **验证**：按 `references/verification.md` 执行与 Tier 匹配的最直接验证，记录 V ID、命令/操作、退出码、直接输出、主体域、断言、环境和被测构建绑定。
5. **Final Sweep**：执行 Drift Detection 并协调最终写集、覆盖和稳定性；第 4 步满足复用条件时可直接刷新为 `FINAL_VALID`，只补跑失效或遗漏项。
6. **交付**：对本次接缝做对抗自审。决策表允许时用紧凑模板交付；例外须用户明确接受，否则 `BLOCKED`。

中断、换人或跨天后 `resume_supported: false`。按控制面保存未知归属和失败历史；需要延续原任务时进入 R1 恢复卷宗，核对完成前停止源码写入。自动回滚只按控制面四项守卫执行。
